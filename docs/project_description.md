# Project Description

## Project Title

Smart Garbage Classification System for Sri Lanka Urban Waste

## Description

This project focuses on developing an intelligent waste classification system using Deep Learning and Transfer Learning techniques.

The system classifies waste images into four categories:

- Plastic
- Paper
- Glass
- Organic Waste

The main objective is to improve waste segregation and support smart waste management practices in Sri Lanka.

- Dataset planning completed
- Preprocessing modules created
- Model structure prepared
- Evaluation scripts prepared
